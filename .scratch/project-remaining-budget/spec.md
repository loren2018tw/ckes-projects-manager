# 專案列表顯示剩餘經費

## 目的

在專案管理頁的專案清單中，除「核定金額」外顯示「剩餘經費」，讓使用者不必進入個別專案的儀表板，就能掌握各專案的經費執行狀況。

## 名詞

依根目錄 `GLOSSARY.md`：核定金額、請購單、實支金額、已動支金額、剩餘經費。

## 需求

### Requirement: 專案列表顯示剩餘經費

專案清單表格在「核定金額」右側新增「剩餘經費」欄位，顯示該專案的剩餘經費（核定金額 − 已動支金額）。已結案專案照常計算與顯示。

#### Scenario: 顯示剩餘經費

- **WHEN** 專案清單載入完成
- **THEN** 每一列在「核定金額」右側顯示「剩餘經費」，格式為 `NT$ 1,234`，負值以紅字顯示

#### Scenario: 未填或核定金額為 0

- **WHEN** 專案的核定金額為未填
- **THEN** 「核定金額」欄顯示「-」，「剩餘經費」仍以核定金額 0 計算（有動支時為負值）
- **WHEN** 專案的核定金額明確為 0
- **THEN** 「核定金額」欄顯示「NT$ 0」

#### Scenario: 顯示計算明細

- **WHEN** 使用者將游標移至「剩餘經費」數值上
- **THEN** 顯示 tooltip「核定 {核定金額} − 已動支 NT$ {已動支金額}」；核定金額未填時顯示「核定 未填」

#### Scenario: 請購單載入中

- **WHEN** 請購單資料尚未載入完成
- **THEN** 「剩餘經費」欄顯示「…」，其餘欄位照常顯示

#### Scenario: 請購單載入失敗

- **WHEN** 請購單資料載入失敗
- **THEN** 「剩餘經費」欄顯示「-」，頁面上方顯示提示 banner，並提供「重試」按鈕重新載入請購單

### Requirement: 經費計算單一來源

專案清單、專案儀表板與請購單管理的金額計算，共用同一組純函式（`src/utils/projectBudget.js`），確保「實支金額」只有一種定義。

#### Scenario: 列表與儀表板數字一致

- **WHEN** 同一專案同時顯示於專案清單與儀表板
- **THEN** 兩處的已動支金額與剩餘經費完全相同

## 非目標

- 不新增「已動支金額」欄位。
- 「剩餘經費」欄位不提供排序，與現有「核定金額」一致。
- 不為請購單新增核銷／付款狀態；所有已建立的請購單都計入已動支金額。
